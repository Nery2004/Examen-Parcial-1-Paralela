# Hardware de Nery

- Sistema operativo: macOS 26.6.2 (build 25G83).
- Arquitectura: `x86_64`.
- Procesador: Intel Core i9-9980HK @ 2.40 GHz.
- Núcleos físicos: 8.
- Núcleos lógicos: 16.
- RAM: 32 GiB (34,359,738,368 bytes).
- Compilador: Apple Clang++.
- Versión del compilador: 21.0.0 (`clang-2100.1.1.101`).
- OpenMP: disponible mediante `libomp` 22.1.8 de Homebrew.
- Método OpenMP: Apple Clang con `-Xpreprocessor -fopenmp`, rutas de
  `/usr/local/opt/libomp` y enlace con `-lomp`.
